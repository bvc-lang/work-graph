# Разбор: масштаб шрифта в настройках по образцу MasterClick

Дата: 2026-06-05

## Запрос

Изучить, как в `D:\Work\01MasterClick\project-php` реализовано управление масштабированием шрифта и вынесено в настройки, затем добавить такой же ползунок в настройках Work Graph.

## Как сделано в MasterClick

В MasterClick масштаб шрифта реализован как пользовательская настройка поверх CSS-токенов:

- В `site/css/main.css` задан базовый множитель `--text-scale: 1`.
- Размеры дизайн-системы переопределены через `calc(<base px> * var(--text-scale))`, например `--Text-Styles-Value-font-size-14`.
- Классы на `html` задают режим: `font-s`, `font-m`, `font-l`, `font-xl`.
- JS хранит выбранный режим в `localStorage` через `getFontScale()` / `setFontScale()` в `site/js/storage-state.js`.
- На старте приложения вызывается `loadSavedFontScale()` / `applySavedMasterFontScale()`, чтобы применить класс до активного использования UI.
- В настройках есть отдельный пункт "Настройки размера шрифта", который открывает модальное окно с `input[type="range"]` на 4 значения.
- Ползунок обновляет подпись, заполнение трека и preview, а сохранение фиксирует выбранный режим в storage.

Ключевой паттерн: не масштабировать отдельные компоненты вручную, а менять один режим на `html`, который переопределяет глобальный множитель шрифтов.

## Решение для Work Graph

В Work Graph уже есть централизованные текстовые токены из `packages/design-tokens/generated/workgraph-dark.css`: `--text-sm`, `--text-base`, `--text-lg`, `--font-size-sm`, `--font-size-base`. Поэтому перенос сделан через тот же принцип:

- Добавлен ранний bootstrap `font-scale-bootstrap`, который читает `localStorage.workGraphFontScale`.
- Поддержаны режимы `font-s`, `font-m`, `font-l`, `font-xl` со значениями `0.875`, `1`, `1.125`, `1.25`.
- В `:root` добавлен `--text-scale` и переопределены основные текстовые токены через `calc(... * var(--text-scale))`.
- В раздел "Настройки" -> "Оформление" добавлен range-ползунок "Размер шрифта".
- Изменение применяется сразу, сохраняется в `localStorage`, переживает reload и не требует серверного состояния.

## Почему так

Это повторяет архитектурную идею MasterClick, но адаптировано к текущей UI-схеме Work Graph: здесь настройки уже встроены в shell, а не открываются отдельной модалкой. Ранний bootstrap снижает мигание размера при reload, а переопределение токенов сохраняет поведение большинства компонентов без точечных правок.
