**Type:** comparison (Diátaxis) — pre-epic / разбор

## Вопрос

Чем Work Graph отличается от GitHub Spec Kit и когда что использовать?

## Вывод

Spec Kit — SDD starter для одной фичи (constitution → spec → plan → tasks → implement). WG — persistent evidence ledger и backlog OS для всего продукта. Не конкуренты: Spec Kit структурирует *старт*; WG ведёт *жизненный цикл* и доказательства.
