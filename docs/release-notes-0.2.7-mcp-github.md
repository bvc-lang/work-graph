## Summary

- npm **Homepage** and README link to [workgraph.ru/en](https://workgraph.ru/en/).
- MCP handlers, prompts, and server entry updates for Work Graph tooling.

## Install

```bash
npx -y @work-graph/mcp@0.2.7
```

Pair with `@work-graph/cli@0.2.10` in your project (see [work-graph-cli release](https://github.com/bvc-lang/work-graph-cli/releases/tag/v0.2.10)).
