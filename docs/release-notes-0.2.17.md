# Release notes — v0.2.17

## Summary

- Work-item hierarchy and epic cascade: auto-close parent epic when all children are done.
- Backlog UI: hide Prompts nav when the section is empty; shell button tweaks.
- MCP handlers and prompts updates vendored into CLI runtime.
- Homepage: [workgraph.ru/en](https://workgraph.ru/en/).

npx @work-graph/cli@0.2.17 init .
npm install
npm run workgraph:ui
