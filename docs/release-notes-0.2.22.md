# Release notes — v0.2.22

## Summary

- **Combobox select:** toolbar and shell dropdowns use custom `wg-select-combobox` (keyboard, listbox, hidden native `<select>` sync).
- **Header wordmark:** Work Graph logo SVG in project header (`/assets/workgraph-wordmark.svg`).
- **Search toolbar:** clear button and search mode labels (local / lexical / hybrid) in RU/EN/PS.
- Checkbox, button, and tabs atom polish.
- Homepage: [workgraph.ru/en](https://workgraph.ru/en/).

## Install

```bash
npx @work-graph/cli@0.2.22 init .
npm install
npm run workgraph:ui
```
