# Release notes — v0.2.23

## Summary

- **Detail drawer → Run agent:** «Делаем» / «Run it» button starts an agent run when the task has analysis, a useful verdict, and an allowed status.
- **Sidebar:** flat nav (no advanced section divider); logo lockup sizing fixes; updated emblem SVG.
- **Public site:** static export ships `.htaccess` with UTF-8 charset for Cyrillic `.md`; doc footer markdown link opens in new tab with icon.
- Homepage: [workgraph.ru/en](https://workgraph.ru/en/).

## Install

```bash
npx @work-graph/cli@0.2.23 init .
npm install
npm run workgraph:ui
```
